# uidata — 화면이 쓰는 그림 파일

`data/` 와 헷갈리기 쉬운데 성격이 다릅니다.

| 폴더 | 무엇이 들어가나 | 저장소에 담나 |
|---|---|---|
| `data/` | 작업물·카테고리 **JSON** | 담는다 |
| `uidata/` | 화면이 쓰는 **그림 파일** | **담지 않는다** |

## icons — 종목 아이콘

```
uidata/icons/005930.png     종목코드가 파일 이름
uidata/icons/index.json     어느 종목이 있는지 · 없는 것은 왜 없는지
```

받는 방법입니다. 몇 분 걸립니다.

```
python tools/fetch-stock-icons.py
```

- 이미 있는 파일은 건너뜁니다. 다시 돌리면 새로 상장된 종목만 받습니다
- 전부 다시 받으려면 `--force`
- ETF 를 빼려면 `--no-etf`

### 저장소에 담지 않는 이유

`.gitignore` 로 빠져 있습니다 (2026-09-16 지시). 세 가지입니다.

- **저장소가 공개입니다.** 사이트는 Cloudflare Access 뒤에 있지만 GitHub 저장소는
  누구나 볼 수 있습니다. 회사 로고 3,700여 개를 거기 올리지 않습니다
- **기록에서 뺄 수 없습니다.** git 은 PNG 를 델타 압축하지 못합니다. 96px 로 담았다가
  나중에 128px 로 바꾸면 96px 판본이 기록에 그대로 남고 용량이 더해집니다
- **서버가 곧 그 기계입니다.** 맥미니를 서버로 두기로 했으므로 파일은 그 기계에만
  있으면 됩니다. GitHub 을 거칠 이유가 없습니다

**기계를 옮기면 거기서 도구를 한 번 돌립니다.** 그것으로 끝입니다.

### 규격을 96px 로 정한 이유

원본은 480×480 입니다. 화면에서 아이콘이 쓰이는 자리는 28~36px 입니다
(`holdings/css/frame.css` · `home.css` · `stock.css`). 고해상도 화면의 2배인
72px 를 덮도록 96px 로 줄입니다.

2026-09-16 실측입니다.

```
원본 480px   45.7 MB
128px        16.0 MB
96px         11.5 MB      ← 이것
64px          7.2 MB      36px 자리에서 모자랍니다
```

줄인 것이 원본보다 크면 원본을 씁니다. ETF·우선주 아이콘은 원본이 이미
1.8KB 라 다시 그리면 되레 커집니다.

### 아이콘이 없는 종목

전부 받아지지 않습니다. 2026-09-16 무작위 표본 실측입니다.

```
보통주      98%     못 받는 것은 최근 상장 종목
ETF        100%
우선주      62%     남양유업우 · LG우 · 하이트진로2우B 등
```

없는 것은 `index.json` 의 `없음` 에 이유와 함께 남습니다. 화면에서는 지금처럼
회사색 바탕에 이름 두 글자가 나옵니다 — 빈칸으로 두지 않습니다
(`holdings/CLAUDE.md` 「데이터 규칙」).

### 배포본에서는 아직 안 보입니다

그림이 GitHub 에 없으므로 `thekjcstudio.com` 에서는 회사색+글자가 나옵니다.
맥미니를 서버로 두고 Cloudflare Tunnel 로 연결하면 그때 전부 보이게 됩니다.
그 작업은 아직 하지 않았습니다.
