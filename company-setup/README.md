# 회사 설립 체크리스트

KJC Studio 법인(주식회사) 설립에 필요한 할 일을 단계별로 정리한 체크리스트입니다.

## 여는 방법

| 방법 | 설명 |
|---|---|
| **메인 사이트 상단 메뉴 `Setup ↗`** | `studio-preview.bat` 실행 후 네비게이션에서 바로 이동 |
| `preview.bat` 더블클릭 (Windows) | 포트 8090 으로 서버가 뜨고 브라우저가 자동으로 열립니다 |
| `preview.command` 더블클릭 (Mac) | 위와 동일 |
| `index.html` 더블클릭 | 서버 없이 파일만 열어도 정상 동작합니다 |
| 주소 직접 입력 | `http://localhost:8080/company-setup/` |

## 화면 기능

- 제목 줄을 클릭하면 체크/해제됩니다
- 항목마다 **메모 입력칸**이 체크박스 아래 들여쓰기되어 있습니다
  (날짜, 담당자, 금액, 다음 할 일 등을 직접 적습니다)
- 체크와 메모 모두 **입력 즉시 자동 저장**됩니다 (오른쪽에 `저장됨` 표시)
- 메모에 내용이 있으면 왼쪽 세로선이 파란색으로 바뀌어 한눈에 구분됩니다
- 메모칸은 글이 길어지면 높이가 자동으로 늘어납니다
- 맨 위에 전체 진행률, 카테고리마다 개별 진행률(`3/6`)이 표시됩니다
- 카테고리 제목을 클릭하면 접기/펴기
- `미완료만 보기` : 끝난 항목을 숨겨서 남은 일만 봅니다
- `메모 숨기기` : 메모칸을 접어서 목록만 훑어봅니다
- `인쇄` : 종이에 뽑거나 PDF 로 저장 (접힌 항목도 펼쳐지고, 빈 메모는 인쇄되지 않습니다)
- `전체 초기화` : 체크와 메모를 전부 지웁니다 (되돌릴 수 없습니다)

## 메모 저장 위치

메모는 **이 브라우저 안에만** 저장됩니다 (localStorage).

- 깃에 올라가지 않습니다 → 다른 PC 로 옮기면 메모는 따라가지 않습니다
- 배포된 사이트에도 올라가지 않습니다 → 남에게 보이지 않습니다
- 브라우저 데이터를 지우면 함께 지워집니다 → 중요한 내용은 `인쇄 → PDF 저장`으로 백업하세요

## 항목 추가·수정

`data/checklist.js` **한 파일만** 고치면 화면에 바로 반영됩니다.

```js
{
  id: "s3-newitem",              // 고유 값 (한 번 정하면 바꾸지 마세요)
  title: "항목 제목",
  desc: "한 줄 설명",             // 생략 가능
  link: { label: "홈택스", url: "https://www.hometax.go.kr" }   // 생략 가능
}
```

> `id` 는 체크 상태를 저장하는 키로 쓰입니다. 기존 항목의 `id` 를 바꾸면 그 항목의 체크가 풀립니다.

## 카테고리 구성

| 번호 | 카테고리 | 내용 |
|---|---|---|
| 01 | 설립 준비 | 상호, 자본금, 임원 구성, 사업장 주소 |
| 02 | 법인 설립 등기 | 정관, 자본금 납입, 인감, 등기 신청 |
| 03 | 사업자등록 | 업종코드, 홈택스 신청, 공동인증서 |
| 04 | 금융·세무 세팅 | 법인 통장, 카드, 세금계산서, 기장 |
| 05 | 계약서와 저작권 | 용역계약서, 저작권 귀속, 포트폴리오 게재권 |
| 06 | 브랜드·운영 | 도메인, 상표, 4대보험, 신고 일정 |

## 주의

세율·수수료 기준과 창업 지원제도는 자주 바뀝니다.
돈이 걸린 항목은 진행 직전에 **세무사 또는 법무사에게 한 번 더 확인**하세요.
이 문서는 빠뜨리는 것을 막기 위한 점검표이지 법률 자문이 아닙니다.

## 독립성

이 폴더는 메인 사이트 리소스를 참조하지 않습니다.
디자인 값(색상·폰트)은 `index.html` 안에 복제되어 있어 단독으로도 정상 동작합니다.
