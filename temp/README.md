# temp — 세션끼리 주고받는 임시 파일

저장소에 남길 것이 아닌 파일을 두는 자리다. **이 README 말고는 아무것도 커밋되지 않는다.**

## 왜 있나 (2026-09-17 지시)

세션마다 제 임시 폴더(`AppData\Local\Temp\claude\…\scratchpad`)가 따로 있는데,
**서로 읽지 못한다.** 실제로 그래서 두 번 막혔다.

- 조사 스크립트를 넘겼는데 받는 쪽이 못 읽어서 내용을 메시지에 다시 적었다
- 시안 HTML 도 같은 이유로 `AppData\Local\Temp\kjc-share\` 로 옮겨야 했다

저장소 안에 한 자리를 두면 경로가 짧고 네 세션이 같은 곳을 본다.

## 무엇을 두나

    시안        화면을 바꾸기 전에 그려 보는 HTML · PNG
    조사 스크립트 API 가 값을 주는지 확인해 보는 일회성 코드
    스크린샷     화면을 찍어 서로 보여줄 때
    내보낸 것    화면에서 받은 JSON 을 잠깐 놓아둘 때

## 두지 말 것

- **키가 든 것.** `secrets.json` 을 복사해 두거나, 응답에 토큰이 실린 파일을 두지 않는다.
  `.gitignore` 가 막아 주지만 그 폴더를 통째로 압축해 보내는 순간 새어 나간다
- **오래 쓸 것.** 이 폴더는 언제 지워져도 되는 곳이다. 계속 쓸 것이면 제자리로 옮긴다
- **저장소에 있어야 할 것.** 문서는 `docs/`, 도구는 `tools/` 가 제자리다

## 쓰는 법

    C:\work\KJCStudio\temp\<세션이름>-<무엇>.<확장자>

    예)  temp\스케줄_툴개발-모달시안.html
         temp\주식페이지_개발-업종조사.py

앞에 세션 이름을 붙이면 누가 둔 것인지 바로 보인다. 네 세션이 같은 폴더를 쓰기 때문이다.

## 치우는 법

쓸 일이 끝나면 지운다. 지워도 저장소에는 아무 영향이 없다.
남의 것을 지우기 전에는 그 세션에 한 번 물어본다.
