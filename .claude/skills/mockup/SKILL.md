# 시안 — 실제 화면 위에 얹고, 재고, 지어내지 않는다 (2026-10-02 지시)

재권님 말씀 그대로다 — **「이거 재부팅하거나 새로 세션추가할때마다 발생하는데 재발방지책 개념정의세션에 만들라해」.**
「이거」 는 시안을 그릴 때 **기존 UI 구성 · 창 크기를 바꾸고 수치를 지어내는 것**이다. 2026-10-02 하루에 한 시안이
v1 → v2 → v3 세 번 연달아 걸렸다 — 검은 띠 · 점선 · 배지 색 → 칸 크기 · 지어낸 값 → 1600px 고정 틀.
**룰은 이미 있었다.** 새 세션이 그 절을 모르고 시작해서 났다. 그래서 절차를 스킬로, 저장 순간 검사를 훅으로 둔다.

**룰 본문은 여기 없다** — `CLAUDE.md` 의 이 셋이다. 이 파일은 **어떻게 지키나**만 적는다.

| 무엇 | 어디 |
|---|---|
| 베껴 그리지 않는다 · iframe 도 낡는다 | 「시안은 실제 화면 **위에** 얹는다 — 베껴 그리지 않는다」 절 |
| 칸 크기 · 열 수 · 배치를 지시 없이 바꾸지 않는다 | 「창 크기·배치는 지시 없이 바꾸지 않는다」 절 |
| 값이 있는 지시는 「됨」 대신 넣은 값 · 색은 변수부터 | 「「됨」 이라고 보고하지 않는다 — 넣은 값을 적는다」 절 |

## 0. 먼저 — 무엇을 드리나 (2026-10-02 지시)

재권님 말씀 — **「이미지로 그려줘 라고 하면 이미지로 그리게 룰잡으라해줘」.** 그날 10:3x 지시가 「투자지표 항목들을 이런
식으로 해보고 싶은데 **이미지** 좀 그려달라」(참고 그림 첨부)였는데, HTML 시안 → 코드 덧그리기(반원 둘)로 흘렀고 그대로
올라갔다. 재권님이 **「이미지부터 그려보라고 하지 않았었나?」** 하셨다. 「시킨 방식이 안 되면 바꾸지 말고 말한다」 는 있었는데
**결과물의 종류가 바뀌는 것**을 짚는 자리가 없었다.

| 지시 낱말 | 드리는 것 | 아닌 것 |
|---|---|---|
| 「이미지」 · 「그림」 · 「이미지로 그려 줘」 | **PNG 한 장** — `tools/show-window.py` 로 띄운다 | HTML 시안 · 쿼리 덧그리기 · 코드 |
| 「화면에서 보여 줘」 · 「붙여 봐」 | 실제 화면에 쿼리 하나로 얹은 것 — 아래 1 | 새로 그린 그림 |
| **둘 다 아니다** — 「그려 봐」 · 「만들어 봐」 · 「이런 식으로」 만 | **만들기 전에 한 줄로 묻는다** — 「그림 한 장으로 드릴까요, 화면에 얹어 드릴까요」 | 짐작으로 골라 만들고 「바꿔서 냈다」 첫 줄로 때우기 — 오늘 사고가 이 흐린 자리에서 났다(작업우선순위 감사) |

- **그리는 길에 HTML 을 써도 드리는 것은 찍은 그림이다.** 실제 화면 위에 얹어 찍으면 아래 1 의 룰(칸 · 폭 · 값)이 그대로 걸린다
- **참고 그림이 붙었으면 그 모양(파이 · 게이지 · 막대 …)을 실제 값으로 채운다.** 「이 크기에는 안 들어간다」 는 그림 위에 적지,
  모양을 빼거나 다른 모양으로 바꾸지 않는다
- **종류를 바꿔야 하면 바꾸기 전에 묻는다** — 「시킨 방식이 안 되면 바꾸지 말고 말한다」 그대로. 바꿔서 냈으면 첫 줄에 적는다
- 그림 이름에 찍은 시각을 넣는다(`…-1215.png`) — 「사진은 낡을 수 없다」 를 쓰려면 언제 것인지가 보여야 한다
- **찍는 폭은 재권님이 그 화면을 보시는 폭이다.** 그림은 폭을 정해야 찍히므로 1 의 ②(폭을 창에 맡긴다)가 안 먹는다. 모르면 묻는다 —
  **다른 도구의 기준 폭(check-layout 의 창 크기 등)을 가져다 쓰지 않는다.** v3 의 1600 이 그 길로 들어왔다(창구 검토)

**무엇이 검사하나 — 이 절은 아직 없다.** 지시 낱말이 대화에만 있어 기계가 못 본다. 아래 3 의 훅은 **1 이하(그리는 법 · 기록)만** 본다 —
「훅이 있으니 됐다」 로 넘어가지 않는다(「「됨」 이라고 보고하지 않는다」 절이 같은 모양으로 적어 둔 자리).

## 1. 그리는 법 — 이 순서대로

| | 할 일 | 하지 않는 것 |
|---|---|---|
| ⓪ | **어디에 그리나를 먼저 확인한다** — 재권님이 보시는 자리가 모달인지 전용 화면인지 · 왼쪽인지 오른쪽인지. 모르면 묻는다. **홀딩스는 모달이 원본이다**(스킬 `modal`) | 전용 화면(`stock.html`)에 얹고 「거기가 아니다」 를 듣기 — 2026-10-02 네 번째 재발이 이것 |
| ⓪′ | **「실제 화면」 은 재권님 창이다.** 바탕은 (가) 재권님이 보내신 스크린샷(찍은 시각을 적는다) 또는 (나) 재권님 브라우저의 저장 상태(패널 편집 · 보조지표 · 서랍 · 창 폭)를 받아 적용한 화면. 없으면 **먼저 받는다** | 헤드리스 기본 배치 · 세션 자기 브라우저 상태 위에 그리기 — 서랍 · 보조지표 · 칸 배치가 재권님 화면과 달랐다(2026-10-02 다섯 번째 재발 · 그 상태는 재권님 브라우저 localStorage 에만 있다) |
| ① | **실제 화면 그 주소에 쿼리 하나**(`?mock=<이름>`)를 붙여, 그 화면 안에서 `temp/mock-<이름>.js` 가 **바꿀 것만** 얹는다 | 화면을 HTML·CSS 로 새로 쓰기 · 축소해 그리기 |
| ② | 틀(iframe)을 쓸 때는 **폭을 창에 맡긴다** — `width: 100%` · `100vw` | `width: 1600px` 같은 고정 폭 · `zoom` · `transform: scale` · 나란히 둔 두 틀(각 틀이 좁아져 화면이 다시 배치된다) · **다른 도구의 기준 폭(check-layout 의 1600 등)을 시안 폭으로 가져다 쓰기** — v3 의 1600 이 그 길로 들어왔다 |
| ③ | **얹기 전후 칸 px 를 DOM 에서 잰다** — `getBoundingClientRect` 로 바꾼 칸과 그 부모 · 형제. 전후가 같은지 파일 안에 적는다 | 「크기는 안 건드렸다」 를 재지 않고 적기 |
| ④ | **값은 화면이 쓰는 그 API 에서 받는다.** 없으면 `—` | 그럴듯한 숫자 · 예시 값 · 「대략」 |
| ⑤ | 색 · 모서리 · 글꼴은 `theme.css` **변수**로 | `#hex` · `rgba(…)` 직접 쓰기 |
| ⑥ | 올릴 때 **바뀐 것을 센다** — 「반원 둘 외에 달라진 것 0개(칸 6개 높이 · 폭 전후 같음)」 | 「됐습니다」 |

**전후 비교를 보여 드리고 싶으면** 나란히 두지 말고 **같은 폭에서 쿼리만 바꾼 두 주소**를 드린다
(`…?code=005930` · `…?code=005930&mock=gauge`).

## 2. 파일 안에 남길 기록 — 훅이 이 두 낱말을 찾는다

         값 출처: /api/kis/price 의 price · high52 · low52 · 없으면 — -->

`.js` 시안이면 맨 위 주석에 같은 두 줄. **「잰 칸」 · 「값 출처」** 낱말이 없으면 저장이 막힌다(아래 3).
재지 못했으면 **「잰 칸: 못 쟀다 — 이유」** 로 적는다. 지어내서 채우지 않는다 — 「못 쟀으면 `0` 이 아니라 「못 쟀다」 고 낸다」.

## 3. 무엇이 검사하나

| | 무엇 | 막나 |
|---|---|---|
| 훅 `tools/hook-mockup.py` (PreToolUse Write · Edit) | `temp/` · 세션 임시 폴더의 시안 파일(이름에 시안 · mock · 목업, 또는 같은 서버 화면을 거는 iframe)에서 ① 틀의 고정 폭(세 자리 px) · 배율 ② 「잰 칸」 · 「값 출처」 기록 없음 ③ 틀 둘 이상 | 기본은 **알리기만**. ① 고정 폭(1000px 이상 `width`)·배율만 막을 수 있다(`KJC_MOCKUP_HOOK=block`) — 정하는 것은 재권님 · qa 재생으로 잼. ② 기록 낱말은 늘 알리기만(막으면 붙이기만 하는 주문이 된다) · 위반이 줄어드는 편집은 막지 않는다 |
| 창구(`홈페이지_정리`) | **바탕 원본(재권님 스크린샷) vs 결과** 를 픽셀로 대 칸 밖 차이 0 을 본다. 바탕이 없으면 **폭 셋(1280 · 1440 · 1920)** 에서 같은 폭끼리 `mock` 없이 / 있게 찍어 **픽셀을 풀어 다른 구간이 얹은 자리뿐인지** 본다 — 두 폭에서 안 겹친 반원이 1440 에서 글자 위에 겹쳤다(2026-10-02 창구 실측). 「잰 칸: 못 쟀다」 가 남아 있으면 돌려보낸다(상용구로 박고 안 고치는 길을 막는다 · 작업우선순위 감사) | 돌려보낸다 |
| 아직 없음 | 「이미지」 가 들어온 요청 뒤 올린 결과가 `.png` 가 아닌 것 — 세션 기록에서 셀 수 있다(**자기 기록만**). 결과물 종류는 기계가 못 본다 | 「봐야 할 자리」 |
| `tools/check-rules.py` | 진짜 화면 파일(`temp/` 밖)에 `mock=` · `temp/mock-` 이 있으면 「봐야 할 자리」 — 부르는 줄이 커밋되는 것 | 알린다 |

**훅이 못 보는 것** — Bash 로 쓴 시안(heredoc · `cp` · qa 재생에서 약 6%) · 이름에 시안·mock 이 없고 iframe 도 없는 html(화면을 새로
그린 것 — 룰이 가장 막으려는 「베껴 그리기」 인데 모양으로 못 가른다) · 시안용 `.css` 를 따로 둔 것 · 숫자가 정말 API 에서
왔는지(기록 낱말이 있는지까지만 본다). **진짜 화면에 넣은 부르는 줄은 커밋하지 않는다** — 시안이 끝나면 `temp/mock-*.js` 와 함께
지운다. 모든 화면이 공용으로 `?mock=` 을 싣는 길은 **아직 없다**(주식 레인 · 보드 카드).
