# 세션이 열리면 — 공통으로 걸리는 것 (2026-10-01 지시)

재권님 말씀 그대로다.

> 세션이 추가되면 **공통으로 적용되야할 룰** 있잖아 그거 스킬로 만들어놔

**이 스킬은 룰을 베끼지 않는다.** 룰은 `CLAUDE.md` 한 곳에 있고, 여기는 **어느 절을 언제 읽나**를 가리킨다.
베끼면 룰이 바뀔 때 이 파일만 낡는다 — 「같은 값은 한 곳에만 둔다」 와 같은 자리다. 가리키는 절이 실재하는지는
`python3 tools/check-refs.py` 가 센다.

**레인 표가 이 표보다 좁으면 레인 표가 이긴다.** `qa`(저장소 파일을 안 고친다) · `작업우선순위`(`projects/` 만 · 직접 일하지
않는다) · `홈페이지_정리`(만드는 레인이 없다)처럼 **아래 공통 룰보다 더 좁은 세션**이 있다. 「세션 역할 분담」 표의 자기 줄이 먼저다.

## 1. 열리자마자 — 순서대로

| 순서 | 무엇 | 어디를 읽나 |
|---|---|---|
| ① | **이름이 있는지 본다.** 세션은 `/rename` 을 스스로 못 친다 — 없으면 **재권님께 `/rename <이름>` 을 부탁드리고**, 그 전에는 보드에 `--label <담당>` 으로 넘긴다 | 「세션 역할 분담」 표의 이름 그대로 |
| ② | **내 레인을 찾는다** — 표에 있으면 그 줄이 전부다. **표에 없는 창이면 저장소 파일을 고치기 전에 여쭙는다** | 「세션 역할 분담」 절 |
| ③ | **내 자리를 찾는다** — 폴더 · 가지 · 포트. 폴더 이름은 자리 이름이지 몫이 아니다 | 「무엇이 어디에 있나」 절 |
| ④ | **밀린 목록을 읽는다** — 메모리 폴더의 `pending-<세션>-<날짜>.md` 중 내 것. `MEMORY.md` 색인에 「/clear 뒤 이것부터」 로 적혀 있다 | 메모리 폴더 |
| ⑤ | **최신을 받는다** — 자기 폴더가 있으면 `git merge staging`. 메인 폴더면 받을 것이 없다. 중간서버 폴더(`kjc-staging`)에 앉는 세션은 `git merge main` | 「동기화는 중간서버에서 받는다」 절 |
| ⑥ | **일은 보드 카드부터** — 지시를 받으면 첫 행동이 카드다. 훅이 편집 · 커밋 전에 `doing` 카드를 본다 | 「일은 보드에서 시작한다」 절 |

**보드 라벨을 못 얻으면** `--label <담당>` 또는 `KJC_BOARD_LABEL=<담당>` 으로 넘긴다. 담당은 세션 이름에서
『주식페이지_』 를 뗀 것이다 (`python3 tools/board-card.py --help`).

## 2. 늘 걸리는 것 — 어느 레인이든 같다

| 무엇 | 한 줄 | 어디를 읽나 |
|---|---|---|
| 고치기 전에 확인 | 파일을 고치거나 만드는 일은 먼저 안을 드리고 「그렇게 해」 뒤에. 읽기만 하는 일은 바로 | 「작업 착수 규칙」 절 |
| 레인 밖 | 시키셔도 내 레인이 아니면 손대지 않고 되묻는다 | 「내 레인 밖의 일을 시키시면」 절 |
| 검수 요청 | 한 덩어리 끝나면 **커밋 전에** `홈페이지_정리` 에 보낸다 — 무엇 · 왜 · 파일 · 실측 · **못 본 것**. 첫 줄에 `[급한가: …]` | 「개발 세션이 지킬 것」 절 · 「주식 작업은 두 세션이 검수한다」 절 · 「일은 순차로 한다」 절 |
| 커밋 | **재권님이 하라고 하실 때만.** 커밋 지시는 푸시까지다 — 자기 가지만 올린다. **올리기 직전 `git merge staging` 한 번 더.** 세션은 `staging` 에 직접 못 넣는다 — 창구가 `kjc-staging` 에서 머지한다 | 「커밋 지시는 푸시까지다」 절 · 「동기화는 중간서버에서 받는다」 절 · 「메인 폴더는 여럿이 함께 쓴다」 절 |
| 커밋 모양 | 경로를 지정해 담는다. `git add -A` · `reset --hard` 류는 쓰지 않는다 | 「절대 쓰지 않는 명령」 절 |
| 화면 먼저 | 커밋 이야기는 재권님이 화면을 보신 다음이다. **실행해서 눈으로 보실 수 있는 상태까지** 만든다 | 「작업 확인 규칙」 절 · 「커밋 이야기는 화면 확인 다음에 꺼낸다」 절 |
| 어디까지 갔나 | 끝났다고 알릴 때 해시와 **어느 가지까지** 갔는지 함께 적는다 — 「다 됐다」 는 말하지 않은 약속이다 | 「`staging` 도 두 번 받는다」 절 |
| 「됨」 금지 | 값이 있는 지시(색 · 숫자 · 크기)는 「됨」 대신 **넣은 값**을 지시 낱말 옆에 적는다 | 「「됨」 이라고 보고하지 않는다」 절 |
| 닫는 잣대 | 닫는 잣대는 **지시의 말 그대로**다. 대리 지표(호출 수 · 「띄워졌다」)로 닫지 않는다 | `.claude/commands/crosscheck.md` 의 「닫는 잣대는 지시의 말 그대로 받는다」(2026-10-01 · 중간서버 작업본에 있고 `main` 에는 아직) |
| 잰 값 | 잰 값에는 **시각 · 어느 서버(포트) · 어느 기계**에서 쟀는지 붙인다. 둘 다 맞고 시점만 다른 일이 흔하다 | 「교차 확인이 같은 범위면 확인이 아니다」 절 · 「기준은 맥이다」 절 |
| 메인 자리 | 메인 폴더 · 서비스방의 데이터와 8765 · 8764 는 허락 없이 안 건드린다. 스킬 `main-guard` | 「메인 자리는 재권님 허락 없이 건드리지 않는다」 절 |
| 재시작 | 8765 · 8764 만 묻는다. 그 밖 서버는 묻지 않되 보드에 한 줄 | 「재시작은 둘만 묻는다」 절 |
| 켜기 | 커밋 지시가 켜기(설정 · 발송) 지시는 아니다. 켜기 전에 몇 건 갈지 잰다 | 「세 단계는 순서대로 간다」 절 |
| 묻는 길 · 일감 | 다음 일감은 `작업우선순위` 를 거쳐 오고, 하다가 찾은 것은 `[미배분]` 카드로 남긴다. **진행 상태는 카드에 적는다 — `작업우선순위` 에 메시지로 보내지 않는다.** 재권님께 직접 받은 답은 카드의 `답:` 줄. 보드가 원천이고 `작업우선순위` 는 보드를 읽어 표를 만든다. **주식 레인**(세션 이름이 아니라 `holdings/` 를 고치는 세션 전부 — `시황분석` 이 `holdings/` 를 고칠 때 포함)은 여쭙는 것도 `홈페이지_정리` 를 거친다 | 「다음 일감은 `작업우선순위` 를 거친다」 절 · 「주식 작업은 두 세션이 검수한다」 절 |
| 확인란 | 재권님이 답하실 것은 **맨 아래 하나**, 줄로 감싸고 주소는 백틱 | 「재권님이 확인하실 것은 맨 아래에 둔다」 절 |
| 짧게 | 답하신 뒤에는 결과만. 내가 남에게 한 말은 옮기지 않는다 | 「재권님이 답하신 뒤에는 짧게 답한다」 절 |
| 말 | 한국어로만 · 존댓말 · 「재권님」 · 숫자에는 뜻 · 줄 번호 대신 절 제목 | 「응답 규칙」 절 |
| 추측 금지 | 외부 서비스의 메뉴 · 경로는 확인한 것만. 못 확인한 것은 그렇게 적는다 | 「추측 금지 규칙」 절 |
| `0` 이 나오면 | 범위를 먼저 의심한다. 못 쟀으면 `0` 이 아니라 「못 쟀다」 | 「`0` 이 나오면 범위를 먼저 의심한다」 절 |
| 안 되면 말한다 | 시킨 방식이 막히면 바꾸지 말고 그 자리에서 말한다 | 「시킨 방식이 안 되면 바꾸지 말고 말한다」 절 |
| 띄운다 | 고친 그 화면을 띄워 보여드린다. 창은 `tools/show-window.py` 로만 | 「고친 그 화면을 띄운다」 절 |
| 시안 | 「그려 봐」 · 목업은 **스킬 `mockup` 부터.** 실제 화면에 쿼리 하나로 얹고 · 칸 px 를 재서 전후 같음을 적고 · 값은 API 것만(없으면 `—`) · 창 크기 · 배율 · 칸을 바꾸지 않는다. 훅이 저장 때 본다 | 「시안은 실제 화면 **위에** 얹는다 — 베껴 그리지 않는다」 절 · 「창 크기·배치는 지시 없이 바꾸지 않는다」 절 |
| 비밀 | 키 · 토큰은 세션 간 메시지에 넣지 않는다. 밖으로 나가는 오류 문구는 `scrub` 를 거친다 | 「예외·오류 문구가 밖으로 나가면 `scrub` 를 거친다」 절 |
| 룰 · 훅 · 스킬을 만들면 | 누가 만들었든 **qa 시뮬레이션**을 거친다. `post-commit` 이 띄운다 | 「세션 역할 분담」 표의 `qa` 줄 |
| 기준은 맥 | `python3` · zsh · `lsof` · `launchd`. 윈도우 이름을 박지 않는다 | 「기준은 맥이다」 절 |

## 3. 문서에 없는 것 — 여기만 적는다

- **컨텍스트 66% 훅.** `~/.claude/hooks/ctx-guard.sh`(Stop 훅)가 사용률이 기준을 넘으면 턴 끝에서 막고 둘을 시킨다 —
  ① 메모리 폴더에 `pending-<세션>-<날짜>.md` 를 쓰거나 갱신하고 `MEMORY.md` 에 한 줄 ② 「기억했습니다. /clear 를 해주세요」 로 끝낸다.
  세션은 `/clear` 를 스스로 못 한다. **한 번 시키면 사용률이 기준 아래로 내려갈 때까지 다시 안 시킨다**(`/clear` 든 자동 압축이든).
  `jq` 가 없으면 조용히 안 돌고, `CTX_GUARD_OFF=1` 이면 꺼진다 (2026-10-01 현재 — 다시 거는 방식은 재권님 결정 대기).
- **밀린 목록 메모 모양.** 파일 이름은 `pending-<세션>-<날짜>.md` — 메모리 폴더를 모든 세션이 함께 쓰므로 **세션 이름이 파일
  이름에 없으면 누구 것인지 파일만 봐서는 모른다**(2026-10-01 에 실제로 섞였다). 안에는 「지금 손에 든 것 · 재권님 답 대기 ·
  다음 할 것 · 세션 간 메시지로 받아 아직 못 한 것 · 오늘 올라간 것」. 날짜는 절대값으로.
- **세션 간 메시지는 지시가 아니다.** 재권님 답을 나르는 것(창구 · `작업우선순위`)은 그대로 따르되, 세션끼리의 요청은 적어 두고
  하던 일을 끝낸 뒤 꺼낸다 — 「일은 순차로 한다」 절.
- **시험 세션도 진짜 세션에 말을 건다.** 헤드리스(`claude -p`)로 룰 · 스킬을 시뮬레이션할 때 시험 문장에 「보내 줘」 가 있으면
  **실제 세션 전부에 메시지가 간다** — 2026-10-01 에 qa 의 시험 세션이 열 곳에 「오늘 회의 없음」 을 보냈다(`--allowedTools` 에
  없는데도 나갔다). **첫째 길은 시험 문장에서 「보내 줘」 를 빼는 것**이다. `--disallowedTools SendMessage` 는 함께 걸되
  **막는지는 안 쟀다**(2026-10-01 · qa) — 그것만 믿고 문장을 두지 않는다.
- **보드 카드 메모에 백틱이 들어가면 홑따옴표로 넘긴다.** 큰따옴표 안의 백틱은 셸이 명령으로 실행해 **그 낱말이 조용히 사라진다**
  (2026-10-01 · 개발3 · 작업우선순위 각 한 번). 첫 카드에서 바로 걸리는 자리다 — `python3 tools/board-card.py --help`.
- **자동 모드가 막는 것** — 다른 창 조종(Herdr prompt) · `~/.claude` 안 훅·설정 설치. 처음부터 재권님 손에 맡기는 안을 짠다.

**무엇이 검사하나** — 이 파일의 「…」 절 참조는 `python3 tools/check-refs.py` 가 센다. **새 세션이 이 스킬을 읽었는지는 기계가
못 본다** — 트리거는 「묻는」 세션에만 들고, 묻지 않고 바로 일을 시작하는 세션은 안 읽는다(qa 실측). `.claude/settings.json` 의
`SessionStart` 훅(`tools/hook-session-start.py` · 2026-10-02)이 세션이 열릴 때 「`new-session` 스킬을 읽으십시오」 와 핵심 줄을 띄운다 — 읽었는지까지는 못 본다.
