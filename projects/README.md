# 프로젝트 관리

클라이언트 작업을 **프로젝트 단위**로 관리합니다. 진행 단계, 마감일, 입금 상태를 한 화면에서 확인합니다.

## 여는 방법

| 방법 | 설명 |
|---|---|
| **메인 사이트 상단 메뉴 `Projects ↗`** | `studio-preview.bat` 실행 후 네비게이션에서 바로 이동 |
| `preview.bat` 더블클릭 (Windows) | 포트 8091 로 서버가 뜨고 브라우저가 열립니다 |
| `preview.command` 더블클릭 (Mac) | 위와 동일 |
| `index.html` 더블클릭 | 서버 없이 파일만 열어도 동작합니다 |

## 화면 구성

**맨 위 요약 4칸**
- 진행중 건수
- 마감 임박 (7일 이내) 건수
- 미입금 금액 — 진행중 프로젝트 중 `잔금 입금` 단계가 체크 안 된 것들의 합계
- 완료 건수

**프로젝트 카드 하나당**
- 클라이언트명 · 카테고리 · 상태(진행중/완료/보류) · 마감일 · D-day
- 프로젝트명
- **진행 단계 9개** — 클릭하면 체크됩니다. 입금 단계(선금·잔금)는 초록색으로 구분됩니다
- 진행률 막대 (`4/9 · 44%`)
- 금액 (자동으로 천 단위 쉼표가 붙습니다)
- 메모칸

**D-day 색상**
- 파란색 : 여유 있음
- 주황색 : 7일 이내
- 빨간색 : 오늘 또는 기한 지남 (카드 테두리도 빨갛게 변합니다)

## 쓰는 법

1. `+ 새 프로젝트` 를 누르면 빈 카드가 맨 위에 생기고 프로젝트명에 커서가 갑니다
2. 클라이언트명, 마감일, 금액을 채웁니다
3. 일이 진행될 때마다 해당 단계를 클릭해서 체크합니다
4. 모든 입력은 **즉시 자동 저장**됩니다 (오른쪽에 `저장됨` 표시)

필터(`전체 / 진행중 / 완료 / 보류`)와 정렬(`마감일순 / 등록순`)로 원하는 것만 볼 수 있습니다.

## 두 PC 에서 같이 쓰기 — 중요

데이터는 **브라우저 안에만** 저장됩니다 (localStorage). 깃에 올라가지 않으므로 Mac 과 Windows 가 자동으로 동기화되지 않습니다.

옮기려면 이렇게 합니다.

1. 쓰던 PC 에서 `내보내기` → `kjc-projects-20260911.json` 파일이 저장됨
2. 그 파일을 다른 PC 로 옮김 (USB, 메일, 클라우드 등)
3. 다른 PC 에서 `가져오기` → 파일 선택
   - **확인** 을 누르면 기존 목록에 합칩니다 (같은 프로젝트는 최신 내용으로 덮어씀)
   - **취소** 를 누르면 기존 목록을 지우고 불러온 것만 씁니다

브라우저 데이터를 지우면 목록도 사라집니다. **주기적으로 `내보내기` 로 백업해 두세요.**

## 진행 단계 바꾸기

`data/stages.js` 한 파일만 고치면 됩니다.

```js
const STAGES = [
  { id: "inquiry",  label: "문의 접수", short: "문의" },
  { id: "deposit",  label: "선금 입금", short: "선금", money: true },   // money: 입금 단계(초록색)
  ...
];
```

> `id` 는 저장 키입니다. 기존 `id` 를 바꾸면 그 단계의 체크가 전부 풀리니, 새 단계는 새 `id` 로 추가하세요.

카테고리(`CATEGORIES`), 상태(`STATUSES`), 마감 임박 기준일(`DUE_SOON_DAYS`) 도 같은 파일에서 바꿉니다.

## 독립성

이 폴더는 메인 사이트 리소스를 참조하지 않습니다. 디자인 값은 `index.html` 안에 복제되어 있어 단독으로도 동작합니다.
