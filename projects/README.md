# 프로젝트 보드

클라이언트 작업을 **카드**로 관리합니다. 트렐로와 같은 구조(칼럼 + 카드)이고, 카드를 버튼으로 옮깁니다.

## 여는 방법

| 방법 | 설명 |
|---|---|
| **메인 사이트 상단 메뉴 `Projects ↗`** | `studio-preview.bat` 실행 후 네비게이션에서 이동 |
| `preview.bat` 더블클릭 (Windows) | 포트 8091 로 서버가 뜨고 브라우저가 열립니다 |
| `preview.command` 더블클릭 (Mac) | 위와 동일 |
| `index.html` 더블클릭 | 서버 없이 파일만 열어도 동작합니다 |

## 구조

```
보드
 ├ 할 일    ← 아직 시작 안 한 작업
 ├ 진행중   ← 지금 붙잡고 있는 작업
 └ 완료     ← 끝난 작업
      └ 카드 = 클라이언트 작업 하나
```

**카드 겉면** — 카테고리 색 띠, 프로젝트명, 클라이언트명, 할 일 진행률(`☑ 3/7`), D-day, 금액·입금 상태

**카드를 누르면** 상세가 열리고 여기서 전부 편집합니다.
- 프로젝트명 / 클라이언트명 / 카테고리
- 마감일 (옆에 D-day 자동 표시)
- 금액 + `선금` `잔금` 체크
- **할 일 목록** — 직접 입력해서 추가, 체크, 글자 클릭해 수정, `×` 로 삭제
- 메모
- 맨 아래에서 칼럼 이동 / 삭제 / 닫기

## 카드 옮기기

카드 아래쪽 `‹` `›` 버튼으로 옆 칼럼으로 옮깁니다. 상세 화면 맨 아래 칼럼 버튼(`할 일` `진행중` `완료`)으로도 됩니다.

## 할 일 입력

상세 화면 아래쪽 입력칸에 적고 **Enter** 를 누르면 계속 추가됩니다.
`기본 세트` 버튼을 누르면 자주 쓰는 할 일이 한 번에 들어갑니다. 세트 내용은 `data/config.js` 의 `TODO_TEMPLATE` 에서 고칩니다.

진행률은 **체크한 할 일 ÷ 전체 할 일** 로 자동 계산됩니다. 할 일이 하나도 없으면 진행률 표시가 나오지 않습니다.

## 맨 위 요약 4칸

- **진행중** — `진행중` 칼럼에 있는 카드 수
- **마감 임박** — 완료가 아닌 카드 중 마감 7일 이내
- **미입금** — 완료가 아닌 카드 중 `잔금` 체크가 안 된 것들의 금액 합계
- **완료** — `완료` 칼럼 카드 수

## D-day 색상

| 색 | 의미 |
|---|---|
| 파랑 | 여유 있음 |
| 주황 | 7일 이내 |
| 빨강 | 오늘 또는 기한 지남 (카드 테두리도 빨갛게) |

## 두 PC 에서 같이 쓰기 — 중요

데이터는 **브라우저 안에만** 저장됩니다 (localStorage). 깃에 올라가지 않으므로 Mac 과 Windows 가 자동 동기화되지 않습니다.

1. 쓰던 PC 에서 `내보내기` → `kjc-projects-20260911.json` 저장됨
2. 그 파일을 다른 PC 로 옮김
3. 다른 PC 에서 `가져오기` → 파일 선택
   - **확인** : 기존 목록에 합치기 (같은 프로젝트는 최신 내용으로 덮어씀)
   - **취소** : 기존 목록을 지우고 불러온 것만 쓰기

브라우저 데이터를 지우면 목록도 사라집니다. **주기적으로 `내보내기` 로 백업하세요.**

> 저장 방식은 나중에 파일 기반으로 바꿀 수 있습니다. 데이터 형식(JSON)은 그대로라 옮겨도 손해가 없습니다.

## 설정 바꾸기

`data/config.js` 한 파일만 고치면 됩니다.

```js
const COLUMNS = [                        // 칼럼 구성
  { id: "todo",  label: "할 일" },
  { id: "doing", label: "진행중" },
  { id: "done",  label: "완료" }
];

const CATEGORIES = [                     // 카테고리와 색
  { id: "3d-modeling", label: "3D Modeling", color: "#4f7eff" },
  ...
];

const TODO_TEMPLATE = [ "레퍼런스 정리", "견적 발송", ... ];   // 기본 할 일 세트
const DUE_SOON_DAYS = 7;                                      // 마감 임박 기준
```

> `id` 는 저장 키입니다. 기존 `id` 를 바꾸면 그 칼럼/카테고리에 있던 카드가 갈 곳을 잃습니다. 새로 만들 때는 새 `id` 를 쓰세요.

## 독립성

이 폴더는 메인 사이트 리소스를 참조하지 않습니다. 디자인 값은 `index.html` 안에 복제되어 있어 단독으로도 동작합니다.
