Phase 1 2026년 4월
UI 제작 완료
  • 홈페이지에 주식 섹션 추가
  • 종목 검색창 및 기본 레이아웃 구성
  • 차트, 재무 카드, 뉴스 UI 설계
  • 로드맵 캘린더 제작
Phase 2 2026년 9월
서버 · 배포 환경 완료
  • 도메인 등록 (thekjcstudio.com) · HTTPS 적용
  • Cloudflare Access 로 사이트 전체 접근 제한 (이메일 인증)
  • KIS 중계 서버를 Cloudflare Workers 로 배포
  • 앱키를 Secret 으로 분리 · 무인증 통로 차단
  • 당초 Mac Studio + Tailscale 계획이었으나, 상시 켜둘 필요가 없는 클라우드 방식으로 변경
Phase 3 2026년 9월
시세 연동 완료
  • 한국투자증권 API 발급 · 실전 계좌 연동
  • 지수(KOSPI · KOSDAQ · KOSPI200) 실시간 반영
  • 삼성전자 · SK하이닉스 실시간 시세 반영
  • 호출량 제어 (캐시 · 호출 간격 · 보이는 종목만 조회)
Phase 4 2026년 9월~
데이터 저장 계층 진행중
  • Cloudflare D1 데이터베이스 도입
  • 일봉 · 재무 · 종목정보를 받아서 저장 (매번 API 를 부르지 않도록)
  • 종목 마스터 구축 — 전 종목 검색 가능하게
  • 전문 차트의 전제 조건. 과거 데이터를 쌓아두지 않으면 호출량이 감당되지 않는다
Phase 5 2026년 10월
전문 차트 예정
  • TradingView Lightweight Charts 도입
  • 캔들 · 거래량 · 이동평균선
  • 보조지표 (RSI · MACD · 볼린저밴드)
  • 기간 전환 (일 · 주 · 월 · 분봉)
Phase 6 2026년 11월
데이터 소스 확장 예정
  • OpenDART — 재무제표 · 공시 (분기 1회 갱신)
  • KRX Open API — 종목 마스터 · 지수 (하루 1회)
  • 네이버 — 뉴스
  • KIS 하나로 모두 받으려던 구조를 소스별 역할 분담으로 전환. 호출량이 줄고 정보량은 늘어난다
Phase 7 2026년 12월
AI 분석 예정
  • Claude API 연동
  • 뉴스 감성 분석 (긍정 / 부정)
  • 종목 종합 리포트 자동 생성
Phase 8 미정
실시간 (검토 중) 보류
  • KIS 웹소켓 — 세션당 41종목 구독, 호출 횟수 제한 없음
  • 상시 켜져 있는 서버가 필요해 인프라가 바뀐다. 분석·기록이 목적이라면 지금의 10초 갱신으로 충분하므로, 단타 매매가 필요해질 때 판단
