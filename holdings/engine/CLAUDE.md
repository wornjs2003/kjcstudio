# KJC Engine 프로젝트

## 프로젝트 개요
- 프로젝트명: KJC Engine
- 소속: KJC Studio
- 목적: 장기 상업용 3D 게임 엔진 자체 개발
- 최종 목표: 리얼리스틱 PBR 기반 자체 렌더러 (Vulkan 백엔드 최종 지향)

- 재권님 (그래픽 디자이너 · 붉은사막 경력)
  - 아트 디렉션 · 비주얼 타깃 설정
  - 그래픽 파이프라인 설계
  - 머티리얼 · 셰이더 컨셉
  - 룩 디벨롭먼트 · 검증
  - 에디터 UX · 아티스트 워크플로우 결정
- Claude (프로그래밍 담당)
  - C++ · GLSL · 시스템 프로그래밍
  - 렌더러 구현 · 툴 개발 · 빌드 시스템
  - 설계 결정 보조 · 기술 리서치
- 공동
  - 기능 우선순위 결정 · 마일스톤 리뷰 · 시각적 검증

## 개발 전략 (하이브리드)
**Phase 1 (Week 1~12): 언리얼 기반 커스텀 렌더링 스택**
- 엔진 배관은 Unreal Engine 5에 위임
- 커스텀 머티리얼 함수 라이브러리 · 포스트프로세스 스택 · 셰이더 · 라이팅 리그 자체 제작
- 매주 가시적 결과물 산출 (쇼케이스 씬, 셰이더 데모, 포트폴리오 클립)
- 목표: 자체 엔진이 뽑아야 할 "완성형 비주얼 타깃"을 확정

**Phase 2 (Week 8~부터 병행): 자체 엔진 Phase 0~ 착수**
- C++ · OpenGL 4.1 (Mac) 기반 빈 창부터 시작
- Phase 1에서 쌓인 파이프라인 설계 감각을 바탕으로 구조 결정
- 궁극적으로 Phase 1의 씬들을 자체 엔진으로 이식하는 것이 성공 지표

## 기술 스택
### Phase 1 (Unreal)
- Unreal Engine 5.x
- HLSL · Material Editor · Niagara
- Blueprint (최소한)
- Python (에디터 자동화)

### Phase 2 (자체 엔진)
- 언어: C++ (C++20)
- 렌더러: OpenGL 4.1 → Vulkan (MoltenVK)
- 빌드: CMake
- 필수 라이브러리: GLFW · GLAD · GLM · Assimp · stb · Dear ImGui · EnTT
- 에셋: glTF 2.0 우선 지원

## 참고 엔진 (교과서용, 코드 복사 금지)
- Hazel Engine (TheCherno) — 전체 아키텍처 학습
- Filament (Google) — PBR 구현
- bgfx — 렌더러 추상화
- Piccolo / GAMES104 — 게임 엔진 커리큘럼

## 작업 원칙
- 참고는 하되 코드는 복사하지 않는다. 개념만 흡수하고 직접 작성.
- 매주 금요일 한 가지 이상 시각적 결과물을 만든다.
- 설계 변경은 작은 단위로 반복한다. 큰 리팩터링은 분기 경계에서만.
- 커밋은 "보여지는 변화" 단위로 묶는다.

## 응답 규칙
- 사용자 호칭은 항상 "재권님"으로 부를 것
- 항상 존댓말로 답변할 것
- 영어 혼용 금지, 한국어로만 답변할 것
- 생각중·작업중·수정중 등 모든 진행 상태 표시 메시지는 영어 금지, 반드시 한국어로 표시할 것
- 파일/코드 편집, 검색, 도구 호출 등 내부 작업 라벨도 모두 한국어로 표시할 것
- 용어는 업계 표준 영어 용어(예: PBR, IBL, HDR, tonemapping)는 그대로 사용하되, 설명은 한국어로
